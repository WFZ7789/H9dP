# R1：眼区追踪何时有用？两种中心的配对复验

**已完成，2026-11-20 UTC。** 上轮的 Good RMSE 7.61 hPa 是一个种子的结果。原配置补跑 seed 9464 得到 **7.87**，同折固定中心为 **7.78**。因此不能说“追踪总比不追踪好”。更稳的用法是让两个模型各自预测，再取等权平均。在三个新轮转种子上，这个基线的 Good / 全体 RMSE 均值为 **7.62 / 9.16 hPa**。新增的可加亮温响应核做到 **7.58 / 9.20**：对 Good 的收益小，对全体没有收益。**不替换默认模型，也没有达到 Good < 5.9 hPa。**

## 数据和比较办法

- 与[上轮](RESULTS_20261118.md)相同的 546 条真实 Himawari 序列、3,261 个可用帧，Good/Fair/Poor = 211/223/112。标签为当前 MOTIS dP，不是实测中心气压。只读复用 `features_xy` 和 `features_tracked`；没有联网、重提取原始数据或增加现场观测。
- 每个种子按 `record_folds` 做 5 折，每条记录只在其外折预测一次。划分不使用名称、年份或标签；不按气旋分组，不设时间缓冲，不删除难例。预测只用影像侧描述及其相对时间；训练侧沿用 R1 的质量/尾部权重，评估侧质量仅分组。折内标准化、GP 目标和训练预算保持不变：每折两种初始化，各 120 步，AdamW lr=0.035，尾部系数 0.45。
- `xy` 和 `tracked` 是**在相同训练记录上分别拟合**的 GP，不是把一套权重用于不同中心。后处理逐一核对源元数据指纹、`seed/fold/record`、质量、目标和完整覆盖；不按 CSV 行号混合，不拟合混合权重。
- `half` = 两个后验均值各占 1/2。`gated` 用图像配准置信度：取本记录有有限值的帧间 NCC 中位数（含得分有效但平移被拒的帧），追踪权重 `clip((NCC−0.80)/0.18, 0, 1)`；无接受平移或无得分时退回固定中心。两种方法都预测全部记录。

## 1. 配准分数不是压力预测收益的开关

基础 GP 在相同记录上的比较。数值为 `tracked RMSE − xy RMSE`（hPa），负数有利于追踪。分箱固定，不使用质量或 dP 选择阈值。

| 图像 NCC 中位数 | 记录数 | 9463 | 9464 |
|---|---:|---:|---:|
| < 0.85 | 118 | −0.73 | −0.41 |
| [0.85, 0.95) | 223 | +0.28 | +0.43 |
| ≥ 0.95 | 205 | −0.07 | +0.15 |

低 NCC 组反而在两次轮转中都从追踪获益。NCC 衡量云图局部相似度，并不衡量改用该中心对压力预测的净收益；结果也不足以证明 Poor 退化是配准误差导致的。因此**不采用单调门控，也不据此把门控方向反过来**。

## 2. 试了哪些新信息

1. **同址暖像元谱 `--warm-column`**：在眼候选半径 12 px 内，分别按 B16、B08 选择最暖 3/20 个位置（包含边界并列值），在同一批位置读取四个波段；记录近峰面积变换和谱差。在宽视图约 80–124 原生像元环带用 B16 最暖的一成作局地参照。覆盖不足的项缺失，不把它当作晴空环境亮温或实测量。
2. **可加响应 `--response additive`**：现有核主要比较整组描述的距离。新增三个核分量，分别让 recent 区域、热结构、内核描述中的**每个标量**在五个固定标准化温度/特征节点上有自己的平滑响应，再求和。尺度和缺失列处理只看外折训练侧；Gram 矩阵由显式特征内积构成，和原核一起学习权重。没有增加训练步数。
3. **可见度交互 `--response visibility`**：仅在上述可加核上乘以两条记录的冷/暖眼软分配向量的内积，允许两类眼区有不同响应。软分配只看影像 B16（过渡中心 258 K、尺度 6 K）；**不输入评估侧 Good/Fair/Poor**。该修改未优于无交互版本。

开发轮转 9463、9464。表中每项是**两个逐种子 RMSE 的算术平均**（hPa），不是把记录数翻倍。

## 4. 更值得追的误差

对可加 / half 的三个复验种子，将逐记录误差记作 `e[i,s]`。Good 上的平均 MSE **57.56 hPa²** 可分成 `mean_i(mean_s(e)^2)` = **54.83** 和 `mean_i(var_s(e))` = **2.73**。即约 **95%** 来自在三种划分下仍保留的逐记录偏差，而非这三次划分间的波动。它**不是不可约噪声**。按平均误差绝对值排序，22 条 Good 记录占这部分平方误差的 **44.9%**；没有把这些记录剔除。

只读后验检查：按原始目录中 MOTIS `pixels` 在 211 条 Good 内的四分位分组（切点 34、88、204），三个 OOF 预测先逐记录平均，四组 RMSE 从小眼像元数到大依次为 **8.29、7.81、7.09、6.29 hPa**。此字段不是 AHI 原生眼半径，结果只是关联。最大的持续误差是 record 188：模型均值 83.39，当前标签 102.4 hPa。

### 合成机制检查：从六帧里挑最暖的一帧，够不够？

另做了一个**无压力标签、无训练**的小实验，而不是把上述关联直接当成成因。给定峰值为 1 的静止二维高斯暖核，先作通量守恒的高斯光学模糊，再对单位方形像元面积积分。每个宽度设置使用相同的 8,192 组合成序列，每组六个独立均匀亚像元偏移，seed 9468，无云、无噪声。指标是**保留的亮温异常峰值比例**，不是压力 RMSE。

| 暖核 σ（px） | 假设光学 σ（px） | 随机单帧均值 | 六帧取暖端的均值 | 像元完美居中上限 |
|---:|---:|---:|---:|---:|
| 0.35 | 0（仅像元积分） | 40.1% | 50.4% | 55.2% |
| 0.35 | 0.55 | 20.4% | 22.8% | 23.9% |
| 1.20 | 0.55 | 75.4% | 77.8% | 78.8% |
| 2.00 | 0.55 | 89.5% | 90.7% | 91.2% |

在这个模型下，挑帧能改善采样相位，但不能撤销像元面积平均。0.55 px 是假设，不是 AHI 标定；这也不是多像元反演精度的上限。完整八种设置见 `synthetic_pixel_phase.json`。**下一步（未执行）**是检验局部多像元的形状和总暖异常是否比单点峰值更能区分“小而暖”和“大而凉”，再用真实影像做同折对照。

## 5. 执行、复现和产物

正常用户，Conda `fy3-aivis-v1`，Python 3.13.15、torch 2.13.0+cu132、RTX 5080。正式拟合均 `torch.compile(fullgraph=True)` + CUDA FP64；后验预测 eager FP64，配对与诊断为 CPU NumPy，无 eager 训练回退。首个 tracked 补跑的首步 **4.13 s**（含编译/启动），稳态中位 **12.19 ms/步**；`additive_xy` 对应 **3.41 s / 12.25 ms**。后续重复命中缓存，不能把缓存命中当作零冷启动。耗时为同步优化步，不含 CPU 特征准备。每折两个拟合的首步和稳态时间均见该运行 `metrics.json`。

外部产物：`/mnt/data/H9dP/runs/r1/iteration_20261120/`。GP 目录有 `run.json`、逐折状态、`predictions.csv` 和 `metrics.json`；`paired/{base,column,additive,visibility,rep_none,rep_additive}/` 有最终配对预测、各组 RMSE/MAE/Bias 和误差分解。`validation.log` 留存检查输出。含外部 MOTIS 压差的后验审计已删除。[压力来源清理](../data/PRESSURE_SOURCES_20261122.md)

实际命令的等价循环如下（仓库根目录；复跑时设 `R` 为新的外部目录，避免覆盖）。使用 `-m scripts.…`：直接运行文件时 `scripts/h9dp.py` 会遮蔽 `src/h9dp`；第一次启动因此在导入阶段退出，未生成拟合结果。

```bash
conda activate fy3-aivis-v1
OLD=/mnt/data/H9dP/runs/r1/iteration_20261118
R=/mnt/data/H9dP/runs/r1/iteration_20261120
mkdir -p "$R/tmp" "$R/paired"
export TMPDIR="$R/tmp" PYTHONPATH=src:. MKL_THREADING_LAYER=GNU OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2
gp() { python -u -m scripts.r1_gp --features "$OLD/features_$1" --output "$R/$2" "${@:3}"; }
audit() { python -m scripts.r1_tracking_audit --output "$R/paired/$1" --xy "$2" --tracked "${@:3}"; }

gp tracked tracked_replication --seeds 9464
gp xy xy_replication --seeds 9463 9464
audit base "$R/xy_replication" "$OLD/spectral_gp_tracked" "$R/tracked_replication"
for m in xy tracked; do
  gp "$m" "column_$m" --warm-column --seeds 9463 9464
  for k in additive visibility; do gp "$m" "${k}_$m" --response "$k" --seeds 9463 9464; done
done
for k in column additive visibility; do audit "$k" "$R/${k}_xy" "$R/${k}_tracked"; done
for k in none additive; do
  for m in xy tracked; do gp "$m" "rep_${k}_$m" --response "$k" --seeds 9465 9466 9467; done
  audit "rep_$k" "$R/rep_${k}_xy" "$R/rep_${k}_tracked"
done
python -m scripts.r1_sampling_probe --seed 9468 --sequences 8192 --output "$R/synthetic_pixel_phase.json"
```

测试：`MKL_THREADING_LAYER=GNU conda run -n fy3-aivis-v1 python -m pytest -q`；在加入末项像元积分检查和 B1 之前实际执行为 **209 passed**，当时 7 个新增/变更 Python 路径的 Ruff 检查通过；没有将该次数作为停止时最终工作树的测试结果。合成测试覆盖同址选点与掩码、Gram 半正定及外折隔离、无配准回退、错折/漏行/重复检测和 MSE 恒等分解；不以单测代替真实记录复验。
