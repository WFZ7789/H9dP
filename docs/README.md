## 文档与实验产物分工

- 每个模型目录的 README 作为入口，PLAN/设计文档与实质性结果报告分开。
- 报告写清实际执行状态、数据范围、协议、指标和局限，不把计划当结果，
  不把训练拟合当验证/盲测精度。
- 命令默认在仓库根目录执行；Markdown 链接相对文档自身。
- 数据、检查点、原始日志和机器运行产物保留在 /mnt/data/H9dP/，不搬进 docs/。
- 历史运行目录中的不可变文档/源码快照不随本次 live 文档整理而迁移或修改。
