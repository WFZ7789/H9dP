# V1 为什么有效（Why it works）

**状态：已完成，2026-11-22。** 固定种子 1，546 条真实 Himawari 记录的记录级五折折外结果，
标签为 MOTIS dP。本文是对已训练 V1 的**诊断性复拟合**，不是新模型、不是新数据：
折号、特征、质量权重、110 步 Adam 与 `torch.compile` 均与
[V1 实验报告](README.md) 相同；完整变体复现正式折外 RMSE 8.901418785056 hPa，
与 `formal/metrics.json` 的差在 10⁻¹³ hPa 量级。机制结论和发布口径见
[发布分析](RELEASE_ANALYSIS.md)，评估口径见[评估口径](../EVALUATION.md)。

本文回答三个不同层次的问题，并分别标注证据强度：

1. **模型行为**：拟合后的 V1 实际把权重放在哪些描述子上？（可干预的消融）
2. **物理机制**：这些描述子为什么与 dP 同向？（相关性 + 物理解释，不是因果实验）
3. **标签共同信息**：8.9 hPa 里有多少只是"复述 MOTIS 的分析逻辑"？（标签结构分析，不能完全分离）

## 1. 一句话结论

**V1 有效的核心不是"运动"，而是"组织度"：红外极坐标描述子把台风编码成
"暖眼 + 冷眼墙/CDO + 方位对称"的静态形态，模型再用 436 条训练记录的相似度
把这个形态映射到 dP。** 6 帧序列相似度和运动特征贡献接近零；眼、眼墙、CDO、
扇区几个特征族高度冗余，去掉任何单独一族最多只差 0.21 hPa。同一机制也与
误差为什么在弱涡和超强两端向中间收缩一致。

## 2. V1 实际不是"运动估计器"

模型名里的 rotation 只占很小一部分。拟合后的 48 个核中，`motion` 族的核质量
只占 **0.5%–1.7%**（五折），去掉全部运动核的折外 RMSE 为 **8.902 hPa**，
与完整的 8.901 hPa 相差 0.000 hPa（配对 bootstrap 95% 区间
[−1.70, +1.71] hPa²，不可分）。去掉 6 帧序列相似度核（`no_sequence`）为
8.909（Δ+0.007）；把运动核和序列核都去掉（`static`）为 8.887（Δ−0.014）。
**在这批数据上，V1 是一个"单帧/近单帧的静态形态估计器"，时间信息只是薄薄一层。**

原因在特征构造：`recent` 用 45 min 时间常数加权，六帧时滞为
−300/−180/−60/−30/−10/0 min，权重从 0.001 到 1，实际由最后 1–2 帧主导；
`angular_motion` 只测同心环纹理的角向位移（像素/分钟），既不是风速，也在
约 18% 的帧上缺测。它能提供的信息本来就很弱，消融结果与之一致。

## 3. 模型在做什么

输入是每帧四个红外波段（B08 6.2 µm、B09 6.9 µm、B10 7.3 µm、B16 13.3 µm）的
原生像素。每帧先由暖核定位重新定心，再在 18 个半径（1–228 原生像素，R304 下
约 2–456 km）× 96 个方位上采样，形成：

| 特征族 | 内容 | 每帧维度 |
|---|---|---:|
| `eye` | 内 8 个半径（约 2–38 km）的 8 通道 × 5 方位分位数 | 320 |
| `wall` | 外 10 个半径（约 50–456 km）的同型分位数 | 400 |
| `relief` | 内圈分位数减 33–58 px 外圈冷尾（暖眼抬升） | 320 |
| `waves` | 四个方位波数带的谐波振幅 | 288 |
| `sector` | 14 个半径 × 12 扇区 × 4 波段的绝对亮温 | 672 |
| `motion` | 15 个同心环的角向互相关位移、峰值、温度变化 | 60 |

每个族再按 `recent` / `latest` / `trend` 汇总。模型为每个"族 × 汇总"建一个线性核
和一个 Matérn 核，对 `eye/wall/relief` 的 `recent` 再加两个样条核，对
`sector/waves` 加三个 6 帧序列相似度核，共 48 个核。训练只学 48 个核质量
和 3 个质量噪声（Good/Fair/Poor），110 步 Adam；预测是 436 条训练记录 dP 的
核加权平均。它没有隐藏层，也没有显式的强度方程。

## 4. 信号阶梯：8.9 是从哪一层降下来的

同一批 546 条记录、同一折号、同一目标，逐层加信息：

| 预测器 | 全体 RMSE | MAE | R² | 预测-目标相关 | 压缩斜率 |
|---|---:|---:|---:|---:|---:|
| 训练折均值 | 21.170 | 17.335 | −0.008 | −0.118 | −0.003 |
| 单个最佳内圈特征（每折在训练侧选） | 15.870 | 12.581 | 0.434 | 0.659 | 0.450 |
| 眼族 25 近邻类比 | 14.572 | 11.650 | 0.523 | 0.735 | 0.451 |
| 眼族线性岭回归（960 维） | 12.384 | 9.743 | 0.655 | 0.812 | 0.608 |
| 暖眼族（`relief`）线性岭回归（960 维） | 12.016 | 9.523 | 0.675 | 0.823 | 0.642 |
| 六族线性拼接岭回归（6180 维） | 9.960 | 7.707 | 0.777 | 0.883 | 0.735 |
| 48 核等权 GP（不学质量，固定噪声） | 9.218 | 7.113 | 0.809 | 0.900 | 0.797 |
| **V1（学习核质量 + 质量噪声）** | **8.901** | **6.830** | **0.822** | **0.907** | **0.826** |

岭回归在训练折内标准化，λ=1.0；第 8 节标签结构模型用 λ=0.1。

三个可读的结论：

- **单个数不够。** 最强的单个描述子（内圈 1 px、B08、暖尾分位）只解释 43% 方差；
  五折中四折选中它，折 2 选中 `wall` 44 px 冷尾。从 15.9 降到 12.4 靠的是把
  整个内圈形态一起用。
- **线性组合是大头。** 六族 6180 维线性模型已经到 9.96，走完 21.2→8.9 的约 91%。
- **核/类比再买 0.74 hPa，学习核质量再买 0.32 hPa。** 等权 GP 与 V1 的差距
  （9.218 → 8.901）说明"用哪些核、各占多重"有实际价值，但价值远小于
  "把六个族的形态拼起来"本身。

## 5. 拟合后的权重放在哪里

48 个核质量的五折汇总（每折先归一化再平均；范围给五折最小–最大）：

| 族 | 质量份额均值 | 五折范围 |
|---|---:|---:|
| `eye` | 69% | 49%–83% |
| `relief` | 12% | 4%–27% |
| `wall` | 6% | 5%–10% |
| `sector` | 6% | 3%–10% |
| `waves` | 6% | 3%–10% |
| `motion` | 1% | 0.5%–1.7% |

按时间汇总（样条核建在 `recent` 上，计入 `recent`）：`recent` 83%
（70%–89%）、`latest` 11%（7%–20%）、`trend` 2%（1%–3%）、
6 帧 `sequence` 4%（2%–8%）。**"最近的眼"是权重中心。**

但核质量在折间高度不稳定：`eye_recent_linear` 单核从 0.28 到 0.56，
`eye_spline_1.8` 从 0.05 到 2.41，折 0 的 `eye` 总份额只有 49%，折 1 达 83%。
这是相关核之间不可辨识的表现，**不能把单核质量当作因果重要性**；下面的消融
才是可干预的证据。

## 6. 消融：冗余的内外结构

做法：固定同一折号、同一特征文件、同一优化器，把不属于该变体的核行置零后重拟合，
其余 48 行的形状不变（等价于删核）。完整变体复现正式折外 RMSE（10⁻¹³ hPa 量级）。Δ 为相对
V1 的全体 RMSE 变化；区间是 5000 次记录级配对 bootstrap 的 MSE 差 95% 区间
（种子 1，hPa²）。

| 变体 | RMSE | ΔRMSE | ΔMSE 95% 区间 | 与 V1 可分 |
|---|---:|---:|---|---|
| **完整 V1** | **8.901** | — | — | — |
| 去 `eye` | 9.110 | +0.208 | [+1.22, +6.37] | 是 |
| 去 `sector` | 9.109 | +0.208 | [+1.03, +6.54] | 是 |
| 去 `waves` | 9.013 | +0.112 | [−2.00, +5.92] | 否 |
| 去 `relief` | 8.912 | +0.011 | [−1.18, +1.56] | 否 |
| 去 `wall` | 8.889 | −0.012 | [−1.99, +1.55] | 否 |
| 去 `motion` | 8.902 | +0.000 | [−1.70, +1.71] | 否 |
| 去样条核 | 8.886 | −0.015 | [−1.66, +1.07] | 否 |
| 去 6 帧序列核 | 8.909 | +0.007 | [−1.17, +1.37] | 否 |
| 去 `trend` | 8.869 | −0.032 | [−2.33, +1.17] | 否 |
| 去运动核 + 序列核（`static`） | 8.887 | −0.014 | [−2.80, +2.11] | 否 |
| 只留内圈三族（`inner_only`） | 9.251 | +0.350 | [−0.07, +12.78] | 否 |
| 只留眼族（`eye_only`） | 11.265 | +2.364 | [+35.52, +60.20] | 是 |
| 去掉内圈三族（`no_inner`） | 10.171 | +1.270 | [+14.91, +34.27] | 是 |

读法：

- **没有单一必需族。** 去 `eye`、`sector` 各只差 0.21 hPa；`wall`、`relief`、
  `motion`、样条、序列、趋势的区间都跨 0。族间重叠太大，任何一家都能被其他家补偿。
- **内圈与外圈是互补的两半。** 只留内圈 9.25，去掉内圈 10.17，两个方向都变差；
  完整模型 8.90。外层扇区/谐波提供的对称性和 CDO 信息不是装饰，但单独拿掉时
  内圈还能顶住。
- **只有把内圈整体拿掉，或只留眼睛，才会显著崩。** 这说明有效信息是
  "眼睛 + 周围冷环 + 外围 CDO 的联合形态"，不是某一个半径或某一个通道。
- **−0.03 hPa 量级的"改善"不是发现。** 折间 RMSE 跨度 2.4 hPa，配对区间也跨 0；
  不要据此删特征或改模型。

配对 bootstrap 把记录当独立样本，但同一气旋的多条记录相关，区间偏窄；
这里用于"不要过度解读小差异"，不用于宣称显著性。

## 7. 为什么"眼睛"是有效信号

全体 546 条记录上，与 dP 相关性最强的描述子（分位数 q=0.97 表示该半径环上
最暖的 3%，q=0.03 为最冷的 3%）：

| 族 | 汇总 | 通道 | 半径 | q | Pearson r |
|---|---|---|---:|---:|---:|
| `relief` | latest | B08 | 1 px（约 2 km） | 0.97 | **+0.693** |
| `relief` | latest | B09 | 1 px | 0.97 | +0.690 |
| `wall` | recent | B08 | 44 px（约 88 km） | 0.97 | **−0.671** |
| `wall` | latest | B08 | 44 px | 0.97 | −0.666 |
| `eye` | trend | B08 | 1 px | 0.20 | +0.579 |

`relief` 是"内圈暖尾减 33–58 px 外圈冷尾"：正值越大，眼区相对周围冷云环越暖。
`wall` 的 44 px 暖尾越冷（负相关），说明整个环越冷、越像深厚对称的眼墙/CDO。
两者其实是同一个"暖眼 + 冷眼墙"图案的两半，这也解释了第 6 节的冗余：
`eye`、`relief`、`wall`、`sector` 都在从不同角度测同一件事。

物理上，dP 是环境气压与中心气压之差。中心气压下降通常伴随眼区下沉增温、
眼墙对流维持、CDO 冷却和云系组织；这些恰好改变 6.2–13.3 µm 的云顶亮温和水汽分布。
所以"红外形态 → 组织度 → dP"是合理的单调链条。但它是**代理关系，不是测量**：
同样清晰的眼睛可以对应不同的中心气压，眼的大小、眼墙是否闭合、切变、干空气、
纬度、卫星天顶角和标签分析误差都不在 48 个核里。

## 8. 标签端：dP 本身是"组织度"的分析量

同一批 546 条记录的 MOTIS 目录列（**不是 V1 输入**，只用于理解标签结构）：

| 列 | 与 dP 的 Pearson r | 单列/多列岭回归 OOF RMSE |
|---|---:|---:|
| `t_cdo`（CDO 温度） | −0.644 | 16.295（单列） |
| `roci`（云系半径） | +0.429 | — |
| `b27` | +0.472 | — |
| `b31` | +0.244 | — |
| `poci` | +0.084 | — |
| `t_cdo + roci` | — | 14.707 |
| `t_cdo + b27 + b31 + roci` | — | 12.393 |

MOTIS 自己的 CDO 温度就与 dP 相关 0.64，仅用四列目录参数就能到 12.4 hPa；
V1 的 8.9 比它好，说明模型确实从图像里提取了这些标量之外的结构。但这也说明
**dP 标签本身是一个高度结构化的分析量**：如果 MOTIS 的分析使用了红外云顶信息，
V1 与标签就共享同一部分信息，8.9 里包含"复述分析规则"的成分。现有数据无法
把"物理技能"与"共同信息"分开；要分开只能靠独立的实测气压。

## 9. 同一机制与误差结构一致

V1 的预测-目标相关 0.907，压缩斜率 0.826，预测标准差 19.22 对目标 21.09：
模型整体上是一个向训练分布均值收缩的单调映射。评估集 546 条中 393 条
≥60 hPa、只有 19 条 <40 hPa，损失是等权 MSE，所以：

- 弱系统（0–30 hPa，仅 5 条）被高估，偏差 +15.3 hPa；
- 超强系统（≥80 hPa）被低估，偏差 −3.5 hPa；
- Good 记录 RMSE 6.93，Poor 记录 10.50，与质量和眼睛清晰度一致；模型也为三档
  质量学了不同噪声。

这不是"模型没看到结构"，更像是"结构 → dP"在两端都饱和：弱涡看起来像普通
云团，超强涡的红外形态（针孔眼、极冷 CDO）差异可能已经很小。要改两端，需要补
两端标签或换信息源，而不是再调核。分箱与小样本限制见[发布分析](RELEASE_ANALYSIS.md)。

## 10. 边界与可证伪性

本文支持的说法：

- 在这 546 条记录、这套折号和这套特征上，V1 的主要信息是静态内圈/外圈形态，
  不是运动或 6 帧序列；
- 特征族之间高度冗余，单族消融不能证明"眼最重要"；
- 8.9 hPa 中的一部分来自 MOTIS 分析标签与红外输入的共同信息。

本文**不**支持的说法：

- 不证明红外形态"导致"气压下降；
- 不证明 8.9 hPa 是未来观测精度；
- 不证明气旋级泛化：记录级五折允许同一气旋的不同时次分处训练/测试，8.9 是
  记录级插值精度。按项目准则这不算缺陷，但也不能当成未来独立观测的精度；
- 不证明换一个气旋、年份或卫星仍保持同样误差；
- 不证明运动特征在别的实现（例如云导风、微波）下也没用，只证明当前 60 维
  角向纹理位移实现没有贡献。

如果要推翻"组织度解释"，最直接的检验是：在独立实测 dP 上，V1 的优势应随
"眼睛/眼墙形态"退化而消失；若在实测集上 V1 仍显著优于只用 `t_cdo + roci`
的基线，才说明它提取了分析标量之外的物理信息。这需要
[实测集准则](../data/OBSERVATION_POLICY.md) 下的独立观测，尚未执行。

## 复现

在仓库根目录、`fy3-aivis-v1` 环境、固定种子 1 下执行（约 54 s，RTX 5080；
`torch.compile(fullgraph=True)`，折外后验 FP64，序列相似度 FP32 预计算，与正式
V1 相同）：

```bash
S=/mnt/data/H9dP/runs/m1_adapt/data_v1
R=/mnt/data/H9dP/runs/v1/rotation_seed1
export PYTHONPATH=src:. MKL_THREADING_LAYER=GNU OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1
python -um scripts.v1_why --source "$S" --features "$R/features.npz" \
  --formal "$R/formal" --output "$R/why_it_works.json"
```

脚本只读已发布的 `features.npz`、`formal/fold*.pt`、`all_meta.json` 和 MOTIS 目录
（`read_catalog` 启动时逐条校验 dP/质量/名称），不重新生成特征、不重新训练新模型；
`full` 变体必须复现 8.9014 hPa。复算产物
`why_it_works.json` 位于 `/mnt/data/H9dP/runs/v1/rotation_seed1/`，不进入 Git。
