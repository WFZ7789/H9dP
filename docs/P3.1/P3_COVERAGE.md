# P3.1 coverage-first 实现与运行说明

> 历史文档：保留当时方案与结果，不作为当前模型路线。命令默认从仓库根目录执行；
> 以后正式训练遵循 [AGENTS.md](../../AGENTS.md)，必须开启 torch.compile，旧 eager 设置仅为历史记录。

## 模型契约

架构名为 `p3-coverage/v1`，完整可训练参数 **121,159**，严格小于 155,000。实现位于 `src/h9dp/p3_coverage.py`，独立配置为 `configs/p3_coverage.yaml`。v2 和 P3 minimal 的默认配置、实现与检查点保留不变。

- 输入为六帧 B08/B09/B10/B16，`[B,6,4,500,500]`，带真实分钟偏移和公共有效掩码。
- 直接读取训练集固定通道归一化后的亮温；没有前置 CNN 或学习式空间降采样，不使用 Satpy。
- 64 维、两层、四头、16 个查询；查询按 4/8/4 分为中心候选、云系、环境槽位。槽位是可学习职责，不是已经识别的气象实体。
- 训练集标签均值/标准差归一化 MSE，逐记录等权；输出为非负 dP，单位 hPa。

参数组成：查询与角色参数 1,216；逐像元通道投影 320；两层读取块 104,838；读出 14,785。

## 观测和路由

每层访问以下观测，固定窗口 K/V 对所有查询共享，不按查询复制：

| 通路 | 每帧观测 | 说明 |
| --- | ---: | --- |
| 全窗背景 | 16×16 | 非学习式掩码归一化摘要，提供全窗搜索和环境上下文 |
| 固定中心 | 129×129 | 每个整数原生像元完整读取，不可被路由删除 |
| 动态原生 | 4×25×25 | 四个候选区域的完整原生窗口，整数位置取最近原生像元 |
| 动态可微 | 4×13×13 | 从原始亮温场双线性采样，提供位置/尺度梯度 |

合计每层六帧 **120,438 个读取位置**，其中部分位置可能重复。大窗口内没有预先汇聚成单个 patch token；使用少量查询到观测的交叉注意力，不做观测之间的全量自注意力。

第一层候选从中心和三个外围锚点出发，经全窗背景条件化后可移动至整个图像范围；实际学会搜索仍需要训练和诊断证明。第二层相对第一层每轴最多移动 16 像元，尺度在 4–48 像元内进行有界对数更新；六帧位置允许不同。

注意力以 2,048 点分块执行精确在线 softmax，训练时对块计算使用 activation checkpointing。无效块返回零而非 NaN，所有局部窗口失效时仍有有效背景。softmax、未投影亮温加权及来源权重在 FP32 中累积；与标准稠密注意力的输出和梯度已用小型合成数据对照。

原生整数读取本身不可微；不能把其坐标梯度归功于整数采样。路由由双线性通路训练，另有梯度测试。每层、每角色、每帧、每通道的亮温读数保留到最终头部，并显式输入中心候选—云系、中心候选—环境差值；不对数值旁路做逐样本 LayerNorm。

## 中心窗口边界与限制

500×500 几何中心落在半像元，129 窗口采用整数中心 250，包含坐标 186–314。检查脚本只使用训练记录，分别报告原始坐标和当前增强分布下的参考点覆盖率。

首轮训练前的资源检查已确认：

- RTX 5080，BF16，物理 batch=4，完整输入训练步可运行，无缺失/非有限参数梯度。
- 检查峰值 allocated 约 1.24 GB，reserved 约 1.41 GB；两次检查预热后的合成步约 0.080–0.117 秒。实际训练包含机械盘读取、增强、评估和保存，不能由合成吞吐直接推断总耗时。
- 一个真实训练记录的只读前向结果有限。

R3 训练参考点在增强后的中心窗口预期覆盖率约 97.1%；FLDK 约 35.8%。中心窗口不是所有核心的覆盖保证，保留全窗搜索通路。参考中心不是人工风眼标签，覆盖率不能称为风眼识别率；也不能从少数 FLDK 验证记录推导来源优劣。
