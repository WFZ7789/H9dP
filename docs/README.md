  C++ 直接推理见 [C++20 推理库](V1/CPP_INFERENCE.md)。
- C1 CDO 连续冷云环，全体 dP RMSE **9.112 hPa**，全体 CDO 温度 MAE 2.315°C。[C1 实验报告](C1/README.md)
- EC1 原生眼区像素与 CDO 结构，全体 dP RMSE **12.195 hPa**，含折外 CDO 温度和不确定性。[EC1 实验报告](EC1/README.md)

## R1：多尺度亮温结构与高斯过程

- [模型入口与协议](R1/README.md)：复用 546 条记录、按记录轮转，眼区追踪不使用压力标签。
- [2026-11-21 图像中心纬度与眼区暖异常](R1/APERTURE_20261121.md)：固定种子 1，完整集加入中心纬度后全体折外 RMSE 为 **8.963 hPa**。眼区总暖异常与面积没有改善小眼组。
- [2026-11-20 追踪与亮温响应复验](R1/TRACKING_RESPONSE_20261120.md)：固定/追踪等权基础 GP 在三个新轮转种子上 Good / 全体为 **7.62 / 9.16 hPa**；可加响应为 **7.58 / 9.20**。没有发现按配准分数门控的收益。
- [2026-11-18 开发结果](R1/RESULTS_20261118.md)：眼区追踪版 Good OOF RMSE **7.61 hPa**，全体 **9.23 hPa**；未达 5.9 hPa，另报告两条原生投落送近地面压力配对的限制。

## 文档与实验产物分工

- 每个模型目录的 README 作为入口，PLAN/设计文档与实质性结果报告分开。
- 报告写清实际执行状态、数据范围、协议、指标和局限，不把计划当结果，
  不把训练拟合当验证/盲测精度。
- 命令默认在仓库根目录执行；Markdown 链接相对文档自身。
- 数据、检查点、原始日志和机器运行产物保留在 /mnt/data/H9dP/，不搬进 docs/。
- 历史运行目录中的不可变文档/源码快照不随本次 live 文档整理而迁移或修改。
