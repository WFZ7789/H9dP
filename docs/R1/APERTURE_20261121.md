## 数据与读数

这轮沿用 546 条 Himawari 真实影像序列、3,261 个可用帧和当前目录中的 MOTIS dP。Good、Fair、Poor 各有 211、223、112 条。每个种子按记录做 5 折，每条记录恰有一个折外预测。固定中心和追踪中心分别拟合，再等权平均。历史探索表中的 RMSE 先在每个种子的完整折外预测上计算，再对三个种子取平均，单位为 hPa。三次轮转复用同一批记录。现场中心气压和未来业务表现均需另行验证。

[上轮误差检查](TRACKING_RESPONSE_20261120.md)发现，MOTIS 眼区像元数少的 Good 记录误差更大。本轮只增加一组影像特征。以已有眼候选为中心，把半径 18–26 个原生像元环带的逐波段中位亮温作为局部背景，在半径 6 和 12 像元的圆内测四个量。

- 圆内最高亮温高出局部背景多少，单位 K。
- 将各像元高出背景的部分相加，单位 K·像元。
- 用正暖异常权重计算有效面积。若只有一个像元贡献，面积为 1，若四个像元等量贡献，面积为 4。公式为 $(\sum w)^2/\sum w^2$。
- 按同一权重计算到暖异常质心的均方根距离，单位为原生像元。

四个波段分别计算，按 R1 既有的 recent/latest/trend 汇总进入几何核。环带要求至少 80% 有效，圆内要求覆盖完整，总暖异常为零时面积和半径记为缺失。半径 12 的圆在固定中心、追踪中心分别取得 3,260 和 3,259 帧的峰值和积分，两个输入版本都覆盖全部 546 条记录。这里只有亮温统计，有效面积不直接对应 MOTIS 的眼区像元计数。

一次无噪声的合成检查说明这些量能读出什么。两个高斯暖核的宽度分别为 0.6、1.2 像元，假定光学模糊宽度 0.55 像元，固定亚像元偏移 (+0.3, −0.2)，对方形像元积分并调至相同的观测峰值 5.00 K。半径 12 内总暖异常分别为 25.65、59.39 K·像元，有效面积为 9.39、22.90 像元。这个确定性检查没有随机种子或压力标签。真实资料上的压力收益由折外预测单独衡量。

## 图像中心纬度的来源

298 条记录有未裁切的 500×500 原生 R3 区域影像，共 1,776 个可用帧，Good/Fair/Poor 为 101/138/59 条记录。按原索引匹配 record、六个帧槽和时间，从最新可用 R3 文件头的标称投影计算几何中心纬度，范围 10.15°N–34.84°N。中心是卫星区域图像的中心。原生子集的视觉特征也从几何中心出发，追踪版本另做图像配准。完整 546 条使用原有视觉特征，对没有原生 R3 导航的 248 条，纬度核贡献为零。两种范围有不同的训练记录、视觉锚点及折分，比较模型变化须在同一范围内进行。

2026-11-20 已运行种子 9465、9466、9467。仅加中心纬度，原生子集 Good 从 7.537 降到 7.057，完整集从 7.583 降到 7.472。当天另试过 3×3 纬度场，分别为 7.048 和 7.488，本次只复验中心纬度。旧 `run_ablation.sh` 与逐折文件保存在 `/mnt/data/H9dP/runs/r1/latitude_20261120/`。

## 复现

工作目录为仓库根，Conda 环境 `fy3-aivis-v1`，RTX 5080，PyTorch 2.13.0+cu132。本次读取本地缓存。正式拟合使用 CUDA FP64 和 `torch.compile(fullgraph=True)`，后验预测用 eager FP64。每折两个初始化，各运行 120 步 AdamW，初始学习率 0.035，训练质量权重 1/0.42/0.25，尾部系数 0.45。影像特征和折划分不使用压力标签。历史探索的种子为 9471、9472、9473。当前报告的正式种子为 1。

下面是当前单种子全量模型的复现命令。复跑时指定新的外部目录，目录内保留每折检查点、逐记录预测、训练耗时与参数。

```bash
conda activate fy3-aivis-v1
R=/mnt/data/H9dP/runs/r1/center_seed1_reproduction
OLD=/mnt/data/H9dP/runs/r1/iteration_20261118
mkdir -p "$R/tmp"
export PYTHONPATH=src:. TMPDIR="$R/tmp" MKL_THREADING_LAYER=GNU OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2
for anchor in xy tracked; do
  "$CONDA_PREFIX/bin/python" -u -m scripts.r1_gp --features "$OLD/features_$anchor" \
    --output "$R/$anchor" --response additive --latitude center \
    --native-r3-index runs/h9dp/native500_v2/index.json --seed 1
done
"$CONDA_PREFIX/bin/python" -m scripts.r1_tracking_audit --xy "$R/xy" --tracked "$R/tracked" --output "$R/paired"
```

历史眼区模型在同一配置上加了 `--aperture`。历史原生子集复用 `latitude_20261120/native_features_{xy,tracked}` 缓存。

本次纬度复验产物在 `/mnt/data/H9dP/runs/r1/latitude_rep_20261121/`。其中原生纯影像首折第一次优化步含编译/启动为 4.05 s，同次拟合后续步中位数为 4.40 ms。眼区方案产物在 `/mnt/data/H9dP/runs/r1/aperture_20261121/`。其 tracked 首折使用已有编译缓存，第一步 0.80 s，后续步中位数 12.42 ms。中断时已完成的 2 个眼区固定中心折和 13 个全量纯影像追踪折按训练记录及折外预测核验后复用，只计算余折。中断前尚未汇总到种子指标文件的若干折缺少首步计时明细，原日志保留两次拟合的总耗时。

两个新目录的 `protocol.txt` 留存拟合前约定。眼区目录的 `finish.sh`、`recover_folds.py` 记录恢复过程，`check_aperture.py`、`aperture_check.json` 记录合成检查和真实覆盖。其 `summarize.py` 从逐记录预测重新核对种子、折、记录、质量和目标，计算各组 RMSE、MAE、偏差并写入 `summary.json`。全套测试命令为 `MKL_THREADING_LAYER=GNU OMP_NUM_THREADS=2 conda run -n fy3-aivis-v1 python -m pytest -q`，214 项通过，变更 Python 文件通过 Ruff。
