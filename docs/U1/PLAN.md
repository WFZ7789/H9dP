# U1：把热结构的反演和直接回归分开检验

## 预定比较

目标是根目录 MOTIS dP。用现有 546 条记录、种子 1、`record_folds(546, 5, 1)`，主指标为汇总逐记录预测后的全体 RMSE。对照 V1 及已有 Q1（已核对逐行预测，分别为 8.901、8.728 hPa）。不以 Good 优先选型，不另换种子。本方案是对已多次开发的同一目录的进一步实验，不是盲测。

- **MOTIS 路线**：只在外折训练侧精确匹配压力无关的热红外参数表。用目录 dP 校准旧版十项热结构与 CDO 缩放；从影像分别反演各个已缩放项，以及先合成再反演的热结构总贡献。检验二者及目录压力与热结构之间的剩余误差。真实参数代入仅是配对记录上的诊断。
- **直接 ML 路线**：不读中间参数，学习各组影像主成分的尺度、组间非线性响应及训练观测噪声；等权优化训练侧留一压力误差。测量眼区在 B16 辐射度暖尾的同址水汽光谱、混合斜率和暖区大小，用眼外场描述环境。给定裁切中心的纬度只作大尺度热环境协变量，不用经度、绝对时次、气旋名、年份或 MODIS 仪器信息检索记录。
- **组合**：直接压力和带剩余误差修正的热结构预测固定各占一半，不根据外折结果调比例。各路线和未修正的中间结果均保留。折外预测不输入目录热红外参数、眼清晰度、气压或其他强度资料。

仅读本地缓存，特征和标签校验记录键、时间槽和来源；标准化、降维、系数及模型权重仅用当前外折训练侧。正式求解使用 CUDA 与 `torch.compile(fullgraph=True)`，不允许静默回退。新产物写入 `/mnt/data/H9dP/runs/u1/`，不动旧实验。实际命令、覆盖、耗时和得失在完成后另行报告。
