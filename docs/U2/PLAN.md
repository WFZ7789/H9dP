# U2：视线方向的暖柱与成对观测误差

[U1](../U1/PLAN.md) 首轮显示，旧热参数可以解释一部分目录 dP，但独立反演再相加弱于误差修正路线。U2 是看过该开发结果后的新试验，不是重新定义 U1 的方案。

1. 在 2 km 眼区网格上读同一柱体不同相对高度的视线投影。高度仅是采样假设，不能据此称作实测暖核高度。环境协变量用观测几何与日照量，不将经纬度、日期组成样本匹配键进行回归。
2. 对配对训练记录，分开上层热异常贡献与眼区/仪器修正贡献。协方差允许它们和目录 dP 的观测误差相关；按记录留一时同时删掉该记录的全部观测。没有旧参数的记录仍以目录 dP 参加训练。推理时只求 dP，不读留出热参数或质量。
3. 用相同的影像核分别训练只读 dP 与联合三输出的模型；报告两者和预定 1:1 均值。不从全体 OOF 学混合权重。另做无新增几何/日照的对照，区分新增输入与联合监督的作用。

沿用根目录压力来源、单种子 1、546 条同折开发评估和全体 dP RMSE。数据全为本地。训练使用 CUDA FP64 和 `torch.compile(fullgraph=True)`；外部产物保存在 `/mnt/data/H9dP/runs/u2/`。这是开发试验，不作为未来业务泛化结论。
