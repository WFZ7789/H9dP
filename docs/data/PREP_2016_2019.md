## 目标与范围

为 2016–2019 年 MOTIS 记录补齐卫星输入，只保留 **原生分辨率的 1000×1000
裁切**，不保留整盘文件、压缩源文件或 500×500 副本。保留 1000×1000 是为了
后续训练能从同一母版随机取 500×500 窗口。

| 项目 | 取值 |
| --- | --- |
| 记录 | `MOTIS_cyclone_records.json` 中 2016–2019 年记录，共 **217** 条 |

本轮不准备实测数据。

## 与 2020 年之后的差异

2020 年之后的 FLDK 是分段产品（每段 550×5500，如 `S0310`），只取需要的一段即可；
2016–2019 年的 FLDK 是 `S0101` 整盘单段，单波段整盘解压后约 60.5 MB。因此这一批
的主要成本是整盘下载与解压，而不是最终裁切结果。

## 网络要求

按 [AGENTS.md](../../AGENTS.md) 的 Network Operations 规定，运行前 unset 所有名称含
`PROXY` 的环境变量，并且不向 AWS CLI 子进程传递代理变量：

```bash
for name in $(env | cut -d= -f1 | grep -i proxy); do unset "$name"; done
env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy -u ALL_PROXY \
  python -m scripts.prepare_2016_2019 --workers 64
```

脚本内 `child_environment()` 会再次剔除子进程环境中的所有代理变量。实测直连聚合吞吐
约 **35 MB/s**；经代理时仅约 2.2 MB/s。

## 获取方式

全部字节通过 AWS CLI 获取，不使用其他下载客户端：

```bash
aws s3 cp --no-sign-request --region us-east-1 \
  s3://noaa-himawari8/AHI-L1b-FLDK/2016/10/03/0440/HS_H08_20161003_0440_B08_FLDK_R20_S0101.DAT.bz2 \
  <scratch> --only-show-errors
```

桶为 NOAA 公开数据桶，无需凭证。整盘基准投影由 `s3api get-object --range` 读取一个
文件头得到，不下载整盘。

## 流水线

单任务 = 一个波段文件，端到端完成：

```text
aws s3 cp 下载到 scratch
  → 内存 bz2 解压
  → 按记录中心裁 1000×1000
  → 窗口亮温定标 + 有效掩码
  → 写入记录数组的对应切片
  → 删除 scratch 源文件
```

- 并发：**64** 个在途任务。
- 整盘解压结果只存在内存中，不落盘；scratch 只短暂存在压缩源文件。
- 按约定不增加额外完整性校验或哈希环节；下载失败重试并记入 `failures.json`。
- 断点续跑：每条记录 24 个任务全部完成后写 `done/<position>`，重跑跳过。
