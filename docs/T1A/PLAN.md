# T1A（test-1 a）设计与实现

技术描述：关系先行的时空小波网络。T1A 的命名含义为 **test-1 a**，不是技术缩写。

## 状态与边界

架构标识为 **t1a/v1**，主实现为 [src/h9dp/t1a.py](../../src/h9dp/t1a.py)，
独立配置为 [configs/t1a.yaml](../../configs/t1a.yaml)。默认配置共有 **757,233**
个可训练参数，不继承旧路线的 155k 参数上限。

模型实现、合成检查已经完成。按用户最新要求，现已完成并通过**单组 24 条真实训练记录的
无增强拟合检查**，未做 8／16／32 三组。**完整训练已按协议早停，最佳验证 RMSE=11.6523 hPa**，
结果与局限见 [完整训练结果](TRAINING_RESULTS_20261101T090846Z.md)。这仍不是独立盲测结论。
合成机制拟合与真实小样本拟合都不是验证集或盲测成绩。
不新增依赖，不解压或复制数据，不修改原始归档、缓存、旧权重。
原有默认架构和配置不变，必须显式选择 T1A 配置。

设计依据是 [P3.1 机制审计](../P3.1/P3_1_AUDIT.md) 中的失败经验：局部关系尚未形成就
汇聚、潜变量读取趋同、小面积结构容易被均值淹没、时间利用不足。
新结构不使用查询、动态窗口、角色路由、注意力或辅助监督。

## 接口与接入

沿用现有模型的三个位置参数：

- images：已经按训练集公共统计量归一化的亮温，浮点 [B,6,4,500,500]；
- time_offsets：相对标签时刻的真实分钟偏移，浮点 [B,6]，严格递增；
- mask：布尔 [B,6,1,500,500]，与四通道共用的有效像元掩码；
- 返回：浮点 [B]，单位 hPa。

内部允许不小于 16 的其他尺寸用于小型合成检查；真实数据契约仍为 500×500。
非法形状、全无效帧、有效区域内的非有限值、非有限/非递增时间显式报错。
掩码外的 NaN/极值先清零，不进入小波或局部统计。

通过 model.py 的 build_model/model_architecture 分派接入原有 engine：
训练目标均值和标准差来自缓存中的训练集统计，随模型 buffer 保存；
输出为 target_mean + target_std × score，不使用 softplus 或截断。
继续使用逐记录等权的标准化 MSE、原有优化器分组、累积、验证和检查点流程；
无须修改 engine.py 或 dataset.py。

**第一版未引入中心/投影坐标通道，也未增加影像重投影。** 当前共享接口不向模型
传入这些坐标；不将裁剪中心当作真实眼位，不声称像素尺度就是固定公里尺度。
若后续加入坐标，必须一并验证投影、增强同步和跨帧配准。
现有部分帧晚于标签时刻，因此该数据契约是时刻附近估计，不能称为严格因果预测。

## 结构

### 1. 带符号的空间分解

每层首先执行固定正交 Haar 分解。每个完整 2×2 单元的 a、b、c、d 产生：

- LL = (a+b+c+d)/2；
- LH = (-a-b+c+d)/2；
- HL = (-a+b-c+d)/2；
- HH = (a-b-c+d)/2。

保留符号，按 LL/LH/HL/HH 拼接。不只保留能量或低频。
全部系数在完整单元内可逆；后续学习式投影仍有损，不能宣称全网络无损。

为避免填充值伪造边缘，只有四个像元都有效的单元才保留系数。奇数尺寸的
底边/右边补为无效，因此部分边界只在更细尺度读出；不对边界插值补细节。
这是保守的有效性策略，后续若使用显著缺测数据，应专门评估有效覆盖损失。

### 2. 邻域关系块

同时输入 F、F−Mean3(F)、F−Mean7(F)，然后执行：

逐点扩展 → GELU → 5×5 深度卷积 → GELU → 逐点投影 → 带尺度参数的残差。

局部均值按有效支持归一化，深度卷积按有效覆盖修正，输出再次应用掩码。
保留绝对特征通路，不进行逐图均值/标准差归一化。
层内没有 BatchNorm、查询角色或人为指定的核心/环境分支。

默认空间层级，每级包含两个关系块：

| 层级 | 尺寸 | 通道 |
| --- | --- | --- |
| 1 | 250×250 | 32 |
| 2 | 125×125 | 48 |
| 3 | 63×63 | 64 |
| 4 | 32×32 | 96 |

训练默认对空间关系块启用非重入 activation checkpointing。只有第一层直接
处理原始亮温的小波系数；后续分解处理已经建立局部关系的特征。

Haar 分块对单像元平移敏感。共享几何增强不会自动证明平移鲁棒性，真实数据
验收仍须加入小平移/边界测试，不能把小波视为鲁棒性保证。

### 3. 有序时间融合发生在特征图上

在第 2、3、4 层保留六帧完整特征图后融合，不先生成六个全局向量。

每个时刻编码三个量：分钟偏移/300、与上一帧的时间间隔/300、归一化偏移平方。
每帧增加 4 维时间编码和有效性位，按固定时间顺序拼接，经过两层 1×1 非线性
网络，再接空间关系块。邻近标签时刻的帧提供特征残差，并非独立预测头。

权重没有正值归一化限制，可以表达有符号的帧间比较；同一帧集合重新排序不再
具有交换不变性。没有直接把未配准的像元差分解释为物理发展率。
融合图的有效支持为各帧支持的并集，缺测处的帧特征和时间编码均为零。

### 4. 多尺度读出与线性回归

对三个融合尺度分别计算有效区域的：

1. 均值；
2. 标准差；
3. 上 10% 响应均值；
4. 下 10% 响应均值。

尾部样本数按每条样本实际有效像元数量计算，不按填充后的总面积计算；
空支持读出为有限零值。不同尺度先各自读出，再拼接到 64 维回归头。
最终线性输出不强制非负，便于检查幅度、偏差和负值比例；不是已证明优于
softplus 的结论。

## 合成检查入口

[scripts/check_t1a.py](../../scripts/check_t1a.py) 默认只做小尺寸合成前向，不读取
真实数据、不更新参数、不写文件。--backward 只计算一次梯度，不执行 optimizer.step。
--fit-steps 是显式启用两个合成监督拟合的入口，失败返回非零退出码。

使用 Conda 环境 fy3-aivis-v1。当前 shell 的 python 会被工具环境覆盖，实际验证
使用该环境的绝对解释器；其他机器应相应调整 PY。不要据此重复安装 PyTorch。

```bash
PY=/home/debian/miniconda3/envs/fy3-aivis-v1/bin/python
export MKL_THREADING_LAYER=GNU OMP_NUM_THREADS=2 MKL_NUM_THREADS=2

"$PY" -m pytest -q
"$PY" scripts/check_t1a.py
"$PY" scripts/check_t1a.py --device cuda --native --batch-size 2 --bf16 --backward
"$PY" scripts/check_t1a.py --device cuda --fit-steps 100

# 可选的代码检查，使用现有工具环境中的 Ruff；未新增项目依赖
ruff check src/h9dp/t1a.py src/h9dp/model.py scripts/check_t1a.py tests/test_t1a.py
```

普通 pytest 不执行合成监督拟合。两个拟合任务各使用 8 条 32×32 合成样本、
47,081 参数的缩宽同构网络、FP32、AdamW、100 次更新、无权重衰减：

- 空间：每对样本四通道直方图完全相同，连续环与断裂/重排结构不同；
- 时间：每对样本帧集合和最终帧完全相同，仅历史顺序不同。

标签为 ±1，常数基线 RMSE=1，预先使用 RMSE<0.1 为通过线。这些数值不是 hPa。
检查仅证明该结构能学习区分给定模式，不证明识别真实风眼、充分利用全部历史，
或在未见样本上泛化；缩宽网络的结果也不替代完整模型的真实数据拟合。
