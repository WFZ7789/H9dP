# 数据准备与观测资料

本目录记录多个模型共用的数据获取协议、来源审计和实际执行结果。
原始数据、日志和机器生成产物保留在 `/mnt/data/H9dP/`，不进入 Git。

- **[实测集永久准则](OBSERVATION_POLICY.md)**：气旋/年份仅为 tag；任何训练、验证、测试气旋均可纳入，
  与训练记录相隔 ≤6 h 不影响纳入或有效性。真实泛化由未来独立观测与长期业务运行检验。
- **[2016–2026 年台风浮标与 JMA/MRI 飞机实测气压普查](TYPHOON_CENSUS_2016_2026.md)**：
  283 个编号风暴；JMA 漂流浮标 169 个年度文件、186,834 条小时气压、580 个候选关联；
  8 条 T-PARCII 原生眼区投落送＋8 条已发表飞机值；全程不使用 BST 气压，论坛来源仅 HALONG 一条。
- **[JMA 扩大采集与航空来源核查](JMA_EXPANSION_AND_AIRCRAFT_20261115.md)**：地面已完成 1,769 条 dP>30 hPa 全量配对，29 站/64 合格站日/25 气旋年份标签；确认 MRI-JMA 合作飞机观测来源，完整原生气压廓线尚未取得，不能以湿度文件冒充气压样本。
- **[JMA 原始现场气压观测：首批 100 条](JMA_OBSERVATIONS_20261115.md)**：官方十分钟日表直接取得 1152 条，193 条 dP>30 hPa，已选 100 条，dP=30.1–62.2 hPa。**BST 实测压力标签为 0**；保留现地/海面气压、质量和 JST/UTC 时刻，不冒称已确认中心压力。
- [NHC 飞机中心气压观测库：来源与实际结果](AIRCRAFT_OBSERVATION_BANK_20261115.md)：
  68 条 CP 飞机中心气压报告＋POCI，dP 31–81 hPa；全部在盘缘，尚未通过卫星时序/眼区可用性核验。
  WP 原始飞机/投落送观测尚未补齐，不冒称已完成可用 H8/H9 测试集。
- [首批失败采集（2026-11-15，已拒收）](OBSERVATION_POCI_COLLECTION_20261115.md)：
  50 条站点代理中 dP >30 hPa 为 **0 条**；原整气旋排除和 6 h 间隔规则已撤销。
  原数据和快照只作失败追溯，不与后续 JMA 真实测站观测混在一起。
- [2016–2019 年 Himawari-8 全盘 1000×1000 裁切](PREP_2016_2019.md)：
