# 模型评估口径

**自 2026-11-22 起，主指标为全体评估记录的 dP RMSE，单位 hPa。** 模型选型和主结果排序都使用这一指标。Good、Fair、Poor 的 RMSE 和 CDO 温度误差用于诊断。历史报告中的 Good 门槛 5.9 hPa 对应当时的 Good 子集。

每条记录等权。令 $N$ 为本次评估记录数，$\hat y_i$ 与 $y_i$ 分别为第 $i$ 条记录的预测值和目标值。

$$
\mathrm{RMSE}_{\mathrm{all}}=\sqrt{\frac{\sum_{i=1}^{N}(\hat y_i-y_i)^2}{N}}
$$

记录级五折先汇总所有折外预测，再按上式计算。每条评估记录须有且仅有一个有限预测。固定种子 1。模型按相同目标、记录集合和评估协议内的全体 RMSE 排序。目录开发评估、真实现场观测测试及合成检查各自报告评估范围、记录数和指标。[压力来源](data/PRESSURE_SOURCES_20261122.md) · [实测集准则](data/OBSERVATION_POLICY.md)
