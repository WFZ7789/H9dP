> 以后正式训练遵循 [AGENTS.md](../../AGENTS.md)，必须开启 torch.compile，旧 eager 设置仅为历史记录。

更新：2026-10-25。本文件描述当前单一 v2 实现，替代原气旋分组采样和划分方案。直接修改实现，不安排模型对照、消融、额外小样本拟合验收或训练前优化器更新预检。

## 输入与标签

六个时次、四个波段 B08/B09/B10/B16，形状 `[B,6,4,500,500]`；有效性掩码为 `[B,6,1,500,500]`。模型使用每帧实际观测中点相对标签时刻的分钟差，保留既有近同步配对规则。输出一个正的 dP 标量，单位 hPa。

直接解析 HSD 文件头、投影和定标系数，不使用 Satpy。R3 保持原始 500×500，FLDK 从已有 550×5500 单段裁取完整 500×500，不缩放、不重投影。标签位置只用于离线裁窗和增强边界，不作为模型输入；气旋可位于窗口内任意位置。

原始 archive、HSD、标签和历史结果均保留。当前 329 条记录，1934 个去重帧。记录对应原 MOTIS JSON 的零基索引，名称、时间及坐标必须匹配。

## 唯一记录身份与划分

样本身份始终是 record ID。同一气旋的不同记录不合并，不因同名气旋绑定采样、权重或集合选择。名称、年份加名称的 storm_id 和质量等级仅保留为元数据及指标标签。

- 2020–2025：232 条全部训练。
- 2026：97 条，按排序后的 record ID 用固定 seed 42 均匀无放回选择 49 条验证，其余 48 条训练。
- 合计：训练 280 条，验证 49 条。选择不使用气旋名称、质量或 dP 值。
- 不同 record 可以属于同一气旋，也可以共享部分历史观测；只禁止同一个 record 重复出现或同时进入两边。数组按帧复用不改变记录身份。

当前索引和两份逐记录清单位于 `runs/h9dp/native500_v2/`。归一化只使用训练记录，每条记录等权、每条记录的六帧等权。共享帧按它在不同训练记录中的实际出现次数计入，不能因为存储去重而改变样本统计权重。

亮温采用训练记录的逐波段均值和标准差。标签使用训练记录的公共均值与标准差；验证复用这些参数。质量等级不改变训练权重。

## 单一模型：250×250 高分辨率、16 个卷积残差块

架构标识：`dense250-residual16/v2`。这里的 16 指卷积残差块数量，每块两个 3×3 卷积。

```text
六帧 4×500×500 亮温、六帧掩码、六个实际分钟差
  ↓
2×2 PixelUnshuffle：原像元移入通道，空间变为 250×250
  ↓
96 个影像通道＋24 个掩码通道＋6 个时间通道
  ↓
可学习 stem，128×250×250
  ↓
16 个卷积残差块，每块始终为 128×250×250
  ↓
最终标量读出头
  ↓
一个 dP，单位 hPa
```

PixelUnshuffle 的 500→250 操作只是可逆的像元重排，不做平均、插值、像元选择或统计网格压缩。六帧及掩码分别保存在通道中，真实时间差以六个平面输入。六帧在同一空间主干中联合处理。

stem 和 16 个残差块均无空间池化、无步长降采样，不再生成 4×4、2×2 或少数空间 token。固定输入下，最终读出头之前的空间分辨率始终是 250×250。

残差块采用 GroupNorm 的卷积分支和未归一化恒等捷径，残差缩放初始为 0.1；stem 不使用逐像元通道 LayerNorm。dilation 按 `[1,2,1,4,1,8,1,16]` 重复两次，交替使用局部卷积与较大感受野卷积，步长始终为 1。

只有完成全部 16 块空间学习后，标量读出头才执行空间归约：在完整特征图上学习位置权重，并结合完整特征图的掩码均值和最大值。它不在主干中间替代高分辨率特征。回归头宽度 128、dropout 0.05，最后线性层以 Xavier gain 0.2 初始化。

输出使用训练标签公共均值与标准差映射到 hPa，再以 hPa 尺度 softplus 保持正值。输入归一化、时间编码及模型均不使用气旋名称、位置标签或质量等级作为预测特征。

## 等权目标与每轮完整覆盖

主损失：

```text
mean(((predicted_dP - target_dP) / training_target_std) ** 2)
```

每条记录权重均为 1。公共训练标签标准差只调整损失数值尺度，最优解与逐记录等权的 hPa MSE 一致；不再按气旋数量或 Good/Fair/Poor 的 sigma 加权。

训练用无放回 shuffle，每轮每条训练记录恰好一次，保留最后不足整批的记录。损失按每个有效 batch 的实际样本数累积，避免尾批权重错误。代码逐轮检查记录 ID 覆盖与重复数。

增强保留所有帧、波段一致的 180°旋转与平移；平移上限降为 32 像元，目标仍须在窗口内；亮温噪声标准差 0.1 K。验证和固定训练指标计算均关闭增强。

## 优化、日志和检查点

| 项目 | 当前配置 |
| --- | --- |
| 环境 | fy3-aivis-v1 |
| 优化器 | AdamW，lr 3e-4，weight decay 1e-3 |
| 调度 | 验证 RMSE 驱动 ReduceLROnPlateau，8 轮平台期，factor 0.5，最低 1e-6 |
| 时长 | 200 epoch，无自动早停 |
| 批量 | 微批量 4，有效 batch 8 |
| 精度 | BF16 网络，FP32 损失和统计 |
| 梯度 | 主干与回归头分别裁剪，阈值均为 5.0 |
| 加载 | spawn，2 workers，prefetch 1，pin_memory=false |
| 执行 | `torch.compile`（`compile_mode=default`），逐残差块激活检查点，保存原始模型状态 |
| 随机种子 | 42 |

训练不依赖任何预检报告，不运行额外小样本拟合门槛。CLI 仅保留 prepare 和 train 两个子命令。当前配置启用 `torch.compile`；首次编译有一次性开销，稳定训练步实测快于 eager。训练和测试默认以正常用户身份执行；仅在确认沙箱限制导致 GPU 不可用或所需外部数据不可访问时，才申请切换到正常用户的非沙箱执行环境，不申请 root/sudo。若没有审批入口则无需审批，不以此阻塞；资源仍不可用时如实报告实际限制。详见 AGENTS.md。

每轮记录：

- 当前训练过程的增强 normalized MSE、增强 RMSE。
- 固定完整无增强训练集 RMSE、MAE、Bias、质量分组 RMSE。
- 固定完整验证集同类指标。
- 训练抽取数、不同记录数、无放回及权重语义。
- 主干与回归头分别的裁剪前范数均值/P95、裁剪比例、平均缩放、缺失梯度张量数和相对参数更新量。

以验证整体 RMSE 保存 best.pt、best_metrics.json、best_train.csv、best_validation.csv；每轮保存 last.pt 和 history.jsonl。run.json 描述运行状态。检查点包含模型、优化器、调度器、随机状态、输入/标签归一化、架构标识和指纹。

新检查点 kind 为 h9dp-training/v2；旧 v1 架构权重保留作为历史产物，不能直接恢复到新架构。启用 `torch.compile` 后配置与代码指纹会变化，旧 eager 运行的检查点不能直接通过严格指纹校验恢复；需要重新启动优化后的运行，或显式实现并验证权重迁移策略。
