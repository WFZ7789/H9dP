# M1：MOTIS 参数小专家测试版

M1 是本次设计的暂定名称。这里的 E 分别预测 MOTIS 的**不同输入参数**，不设路由器，不混合相同目标的专家输出；数学模型 M 将这些参数组合为 dP。

**状态：已完成表格数据审计、模型实现、两个开发运行和一次最终验证（2026-11-13 至 2026-11-14 UTC）。判定为未达组合目标。** 最终 49 条：M5 组合 RMSE 14.565 hPa，同协议直接回归对照 12.947 hPa；参数专家均优于常数基线，但线性组合放大了参数误差。

## 新数据自适应调整（2026-11-14 开始）

继续 M1 路线，合并新旧数据，不永久封存旧验证记录；按气旋轮换的嵌套交叉拟合与短段诊断。已完成独立 5/12 epoch 与固定 M5 联合微调 1/3 epoch，当前已暂停；211 条 Good 的最低已观察开发 RMSE 为 **11.998 hPa，未达 5.9**。这是新的气旋分组协议，不能与旧 18 条 Good 直接比较。旧测试版的失败判定不等于新实验结果。

- [新数据分段调整协议](ADAPT_PLAN.md)：修复种子/缺帧处理、固定学习率轨迹、OOF 校准，以及由误差交叉项诊断引出的联合 dP 微调。
- [2026-11-14 分段开发记录](ADAPT_RESULTS_20261114.md)：新旧数据轮换、实际短段指标、人工诊断与下一步；不是盲测成绩。
