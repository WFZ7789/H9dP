# M1 新数据分段调整协议

## 状态和目标

2026-11-14 UTC 开始实施。**这是自适应开发，不是新盲测。** 用户要求不永久锁定/封存数据；目标是改善 MOTIS Good 的 dP RMSE，最终希望低于 5.9 hPa。短轮次只用于诊断，不预先声称达到目标。

原 M1 测试版和历史产物保持可追溯，见 [RESULTS.md](RESULTS.md)。新实验使用独立目录，不覆写历史运行。

## 本轮改动

1. 保留五个独立专家及原参数预算（合计 86,425 参数），不先扩大网络。
2. 在构造模型之前设置种子；检查点保存优化器、训练子集、随机状态和 shuffle generator，支持在同一实验目录增加目标 epoch 后继续训练。
3. 使用固定可重放学习率轨迹：初始 3e-4，第 13、25 轮各减半，不再把 dev 的最佳轮数与另一套 final 调度混用。
4. 缺帧保留有效性掩码；空区域统计不参与归一化，不能把 0 K 占位符变成极端特征。
5. M5 先用当前训练侧的真实参数拟合先验，再用**内层 OOF 的预测参数**做带先验的 Ridge 校准，修正预测收缩和相关误差。Ridge alpha=10，截距不惩罚，斜率标准化后惩罚。
6. 专家损失和校准损失使用 Good/Fair/Poor 权重 2/1/0.5，全部为正；质量仅作训练权重和指标标签，不作预测输入。
7. 训练启用 torch.compile、CUDA BF16；编译失败不得回退。推理评估沿用 M1 的 eager BF16，明确与训练执行方式区分。未配置 activation checkpointing，与小型 M1 原协议一致。

## 数据与兼容性

- 旧 native500 缓存的 train 和 validation 合并使用，共 329 条；既有 49 条不再永久封存。
- 新增 2016–2019 数据共 217 条，全部能精确配对旧版五参数标签，其中 Good 90 条。
- 合计 546 条有影像记录、447 条有五参数标签。无参数标签的记录不虚构标签，但其 dP 可用于训练侧的第二阶段校准。
- 新数据 15 条各缺一帧，不排除整条记录；缺测值不作为有效亮温。
- 原始 JSON 共 562 条，当前两份影像缓存未覆盖的 16 条无法凭空加入，本轮不下载数据。
- 为保持旧 M1 物理尺度，新数据从 1000×1000 固定中央裁出 500×500，不缩放、不重投影；并非利用了全部 1000×1000 背景。
- 新缓存仅保存 nominal 扫描开始时间，本轮按 nominal 计算时间差；旧缓存仍使用实际观测中点。两者不同，必须作为已知限制报告。
- 新缓存裁窗固定于标签位置，区域中心在六帧中暂使用同一目标中心；不伪造历史运动轨迹。旧数据使用原有逐帧中心。该差异可能影响早期帧，后续需做时序/区域敏感性诊断。
- 原始数据不改；派生量和所有运行产物均放在 `/mnt/data/H9dP/runs/m1_adapt/`。

## 不永久锁定数据的评估方法

使用按 `year:name` 分组的 **2 外折 × 2 内折嵌套交叉拟合**：

1. 外折轮流评估不同气旋；该外折专家、归一化、真实参数先验和校准器都不能使用当前外折评估记录。
2. 外折训练侧再分两折，生成预测参数 OOF，供校准器训练；不能用专家训练内预测代替。
3. 每条可用记录在一轮中均被外折评估一次，同时在另一外折参与训练；不永久隔离任何 record。
4. 同一短实验内暂停/恢复保留折定义，以便比较学习轨迹；下一实验可以换 seed 重新分组，不存在全项目固定不可触碰集合。
5. 轮换分数仍会被人工用于调参，因此只能称开发 OOF 指标，不称独立测试或无偏最终泛化结果。
6. 外折基础专家只用约一半可用记录训练，内折更少；与旧版 230/49 单划分不是同预算受控比较。

## 分段诊断

首段每个专家训练 5 epoch，然后暂停检查：

- 总体/Good/Fair/Poor 的原 M5 与预测参数校准 M5 RMSE、MAE、Bias；
- 各参数特别是 Good B36、Eye size 的误差、真实/预测标准差；
- B33 对 Good 的虚假非零修正；
- 数据来源、缺帧和气旋层面的误差集中；
- 首步（含编译/缓存加载）与后续 epoch 的稳态耗时。

5 epoch 不是 E3/E5 已充分训练的假设。检查后再决定继续训练、改变损失或实施输入/特征消融，不预先启动长训练。

## 根据短段结果执行的协议修订

5/12 epoch 独立训练后，观察到单参误差下降但 dP 恶化，故停止延长独立训练。随后已执行固定 M5 的联合微调：dP 归一化 MSE + 0.25×参数辅助 MSE，lr=3e-5，新 AdamW，先 1 epoch 检查、再恢复至 3 epoch。无参数标签的记录只监督 dP；不增加网络参数。联合训练仍使用原外折隔离和 compile + BF16，评估 eager BF16。

这是基于结果新增的自适应修订，不伪称预先冻结。实际完成指标、误差分解、参数语义取舍与限制见 [分段结果记录](ADAPT_RESULTS_20261114.md)。目前已暂停，尚未达到 5.9 hPa。

## 实际命令

仓库根目录、正常用户、环境解释器：

```bash
PY=/home/debian/miniconda3/envs/fy3-aivis-v1/bin/python
export MKL_THREADING_LAYER=GNU
export PYTHONPATH=src:.
df -B1 / /mnt/data
"$PY" -m scripts.m1_adapt prepare --config configs/m1_adapt.yaml
"$PY" -m scripts.m1_adapt probe --config configs/m1_adapt.yaml \
  --run-dir /mnt/data/H9dP/runs/m1_adapt/round1_20261114 --epochs 5
# 经人工诊断后，可用同目录和更大的 --epochs 恢复；不是每段重新初始化。
```

无网络操作；不下载数据、检查点或依赖。编译缓存设置在外置数据盘；准备前检查根分区实际/预计用量不超过 375,000,000,000 bytes。
