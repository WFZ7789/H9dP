# T1A（test-1 a）

T1A 的名称含义为 **test-1 a**。技术路线为关系先行的时空小波网络，
不是旧模型的查询/窗口路线。完整模型 757,233 参数。

- 模型已实现；合成检查和原生 BF16 前反向通过。
