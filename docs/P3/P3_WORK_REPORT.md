## 一、目标与物理边界

本轮目标不是亮温预测、图像重建或风速估计，而是从指定分辨率的多通道亮温观测直接回归最终 dP。模型需同时保留核心区细节、亮温数值和外围环境信息。

设计要求如下：

1. 无前置 CNN 或空间特征编码器；允许逐像元线性维度映射。
2. 通过动态分辨率注意力兼顾局部精细观测与大尺度背景。
3. 完整模型参数量小于 155k，统计包含输入映射、动态路由和回归头。
4. 防止上一版明显的过拟合，但不能通过过度压缩观测牺牲关键物理信息。
5. 保持现有逐记录等权目标和数据配置，便于与既有基线比较。

物理解释必须遵守以下边界：

- 成熟非 ML 方法利用的暖心距平、暖心高度及 CDO 高度相关线索，是任务设计依据，不是本轮已完成的显式反演结果。
- B08–B10 的水汽通道响应受到环境温湿廓线和云的影响，不能将三个通道固定对应为三个气压层温度。
- 不把学习到的隐变量直接命名为真实层温或暖心高度，也不把 B16 单通道等同于完整温度廓线反演。
- 注意力读到某处、读数得到保留和该观测确实改善 dP 推估，是三个不同的验证问题。

## 三、模型结构与参数预算

输入为 `[B,6,4,500,500]`，输出为 `[B]`。六帧共享参数，使用实际观测时间差，而非假定规则等间隔序列。

每块先进行查询间自注意力和背景交叉注意力，再预测各查询、各帧的读取位置与尺度；随后联合读取背景、原生像元与动态尺度采样。两次交叉注意力调用共享参数。

| 组件 | 配置 | 参数量 |
| --- | --- | ---: |
| 逐像元输入映射 | 四通道 → 64 维 | 320 |
| 查询 | 16 个、64 维 | 1,024 |
| 两个注意力块 | 每块含自注意力、交叉注意力、FFN；4 头，FFN 64→128→64 | 100,480 |
| 两个动态路由器 | 每个 64→32→3，输出 x/y 偏移与尺度 | 4,358 |
| 回归读出 | 归一化隐特征与四通道亮温摘要，68→32→1 | 2,369 |
| **合计** | **构造时拒绝参数量 ≥155,000 的配置** | **108,551** |

每个注意力块的读取配置：

- 全局：每帧 8×8 掩码亮温均值，共 384 个背景观测。
- 原生精读：每个查询、每帧读取像元对齐的 3×3 原始像元。
- 动态尺度：每个查询、每帧在预测范围内读取 5×5 双线性采样点。
- 每个查询跨六帧共 204 个局部观测；原始场不被永久删除，但并非所有像元都被精读。
- 最后一块的注意力权重直接汇聚固定标准化后的四通道原始读数，绕过 learned value projection 与 LayerNorm，再交给回归头。

重要区别：**5×5 动态采样点不是完整高分辨率窗口；“保留原图可回访”不等于“关键细节实际可见”。**

## 七、失败判断与原因分级

### 7.1 已经确认的事实

1. P3 明显弱于既有 v2，参数预算达标不等于任务达标。
2. 最佳检查点的训练误差仍高，输出幅度明显收缩；后期训练继续改善而验证略恶化。
3. 相较上一版大的训练／验证间隙，P3 的首要表现是观测／表达瓶颈与欠拟合，后期兼有轻度泛化恶化。
4. 屏蔽动态细读后验证 RMSE 变化很小，当前动态机制的有效性没有得到支持。
5. 原生精读在后层更少接近记录中心；最后的数值旁路只使用末块读数。

### 7.2 结构上可定位、但因果作用仍待对照验证的问题

- **粗背景与稀疏点之间缺少完整精细窗口。** 8×8 背景每格覆盖约 62.5×62.5 像元；3×3 原生读取与 5×5 稀疏采样无法保证看见小眼、眼墙边界和局部温差。
- **路由不是逐层受约束细化。** 每块位置重新相对初始锚点预测，允许后层把前层已接近核心的读取移走。
- **读出过早混合角色。** 回归头对查询隐特征及亮温摘要取平均，没有显式保留核心、云系和环境的独立读出与差异关系。
- **训练信号不足以保证搜索有效。** 测试已证明路由梯度存在，但非零梯度不等于位置更新具有气象意义。

本轮设计的关键偏差是：将减少参数和减少有效观测绑定，并把“原始场尚未删除”误当成充分的信息保障。不能仅根据本次失败，就否定 <155k 模型的可行性；同样也不能保证换一种读取方式必然达到旧模型精度。

## 九、下一阶段建议：尚未实施

保持原始亮温直接输入、无前置空间编码器及总参数 <155k 的约束，优先修正读取机制，而不是优先增加 dropout、延长原版训练或扩大主干。

### P0：完整窗口与核心保底覆盖

- 将稀疏点精读改为窗口内完整原生像元读取；仍直接对亮温建立注意力，不引入 CNN 预编码。
- 为中心区域保留不可被动态路由删除的精细通路，动态区域用于补充核心、眼墙、CDO 和外围环境。
- 窗口大小与位移范围根据实际像元尺度及训练集中心偏移统计确定，不能用验证集标签逐样本指定读取位置。

### P1：受约束的逐层路由

- 后层相对前层位置进行小步细化，不重新从固定锚点任意跳转。
- 保留已有精读结果，使后层移动不致令之前读到的数值失去直接读出通路。
- 分别记录路由位置、尺度、核心覆盖和输出变化；不只展示注意力热图。

### P1：核心—环境分开读出

- 保留不同区域及不同通道的观测身份，再学习差分与交互。
- 不提前把所有区域平均成一个亮温摘要。
- 不将水汽通道的亮温差包装成未经验证的真实层温距平或暖心高度。

### P2：保持可比性并补充独立评估

- 保存当前 P3 配置、权重和诊断，作为失败基线，不覆盖原实验。
- 新版本继续按同一逐记录目标和划分报告主结果，明确区分结构改动与其他训练改动。
- 同时报告训练／验证误差、预测幅度及强弱 dP 区间偏差；不能仅看一个总体 RMSE。
- 另行设计按台风分组、帧不重叠的评估，不替换当前用于复现的基线划分。
- 最低目标是稳定改善当前 15.069 hPa 验证 RMSE，并检验能否接近既有 10.963 hPa；这只是待验证目标，不是效果承诺。

## 总结

本轮完成了小于 155k 参数的直接亮温 Transformer、训练接入、数值与梯度测试、一次正式训练及只读诊断，但没有达到改善 dP 推估的目标。最有价值的结论是：**小模型应限制容量，而不是限制关键观测的可见性；原始亮温保留、路由可微和参数量达标，都不能替代任务指标与有效读取证据。**
